FIREBASE FIRST
1. Open Firebase Console and select the project's existing Firebase project.
2. Authentication > Sign-in method > Anonymous > Enable > Save.
3. Open the included firestore.rules in a text editor and copy ALL its contents.
4. Firestore Database > Rules: replace the editor contents, then click Publish.
   Pushing this file to GitHub does not publish the rules automatically.
5. If Identity Platform automatic anonymous-account cleanup is enabled, turn it off
   to retain guest sign-in access beyond 30 days.

GITHUB DESKTOP / NETLIFY
1. Extract this ZIP.
2. Open your existing project-little-bridge-source repository in GitHub Desktop.
   Fetch origin and pull any remote changes before copying.
3. Click Show in Explorer.
4. Copy ALL contents from this extracted update folder INTO the existing repository.
   Merge folders and replace matching files. Do NOT delete your existing project.
   Keep your existing app/layout.tsx, favicon, public images/audio, and other files.
   Do not nest the update folder inside the repository.
5. In GitHub Desktop, review changes. Summary: Update Prototype 03 and guest cloud saving
6. Commit to main, then Push origin.
7. Wait for Netlify > Deploys to say Published, then refresh projectlittlebridge.org.

VERIFY ON YOUR REAL WEBSITE
- Continue as guest and accept cloud saving, or use Save existing progress online.
- Complete an activity, reload, and check the correct profile's history.
- Confirm the guest UID appears in Firebase Authentication > Users.
- In Firestore, inspect users > that UID > children > profile ID > events.

Existing browser data can migrate only when the visitor returns to the SAME domain
in the SAME browser and accepts the upload notice. The review preview cannot read
browser progress stored on projectlittlebridge.org. Keep browser data until sync succeeds.
Guest and adult sign-in data remain separate. Clearing browser data can lose access to
the anonymous guest account, even though its cloud records remain.

bridge search icon. Existing site content/assets must stay in your repository.
